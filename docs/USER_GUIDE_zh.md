## 2. 安装与启动

1. 安装 Python ≥ 3.8（Windows 用官方安装器；Linux 另装 `python3-tk`，见项目介绍文档）。
2. `pip install pyserial`（或 `pip install .`）。
3. 启动：`python main.py`，或安装后 `ecom start`。
4. 退出：关闭窗口或终端 `Ctrl+C`。

> ⚠️ 若提示缺少 tkinter：Linux 下 `sudo apt install python3-tk`（或对应发行版命令）。

---

## 3. 连接串口

1. 在左侧「串口配置卡」选择**端口**（下拉含设备全名，如 `COM78  USB Serial Port`）。
2. 设置**波特率/数据位/校验位/停止位/流控**（默认 115200·8·None·1·None）。
3. 可选勾选 **DTR/RTS**（勾选=拉低）。
4. 点「打开串口」，按钮变「关闭串口」，状态栏点亮并显示已连接。

> 打不开：检查端口占用（是否其它工具已打开）、波特率是否与设备一致、是否有读写权限（Linux 需加入 `dialout` 组）。

---

## 4. AT 命令调试（AT 模式）

- 在命令输入框输入 AT 指令，选择**发送类型**（ASCII/HEX/DEC/BIN）与 **send-on-enter 后缀**（None/CR/LF/CR-LF/SPACE/STX-ETX/NULL）。
- 点「发送」或按回车；右侧输出区实时显示 **TX（蓝）/ RX（绿）**。
- 显示选项：是否加时间戳、方向、CRLF 转义、HEX 显示（可在「视图」切换）。
- 可用「开始/停止日志」把收发记录写入文件（与输出框逐字节一致）。

---

## 5. AT list 管理与循环发送

**AT list** 是一张可编辑的命令表，每行含：勾选(参与)、AT命令、发送类型、后缀、HEX、Enter、行间隔(ms)、预期结果、匹配模式。

- 双击某行可**发送该行**；右键可**编辑**。
- 底部有「前一页/后一页/全选/添加页」；**添加页**会追加一页空行。
- 设置**运行次数**与**间隔(ms)**后点「运行」，按勾选行循环发送；「停止」终止。
- 可**导出/导入**命令组（JSON）到左侧命令组下拉，随用随取。

---

## 6. 压力模式（核心功能）

> 切换到「压力」模式后，右侧为压测配置 + 压测 AT list + 输出统计。

### 6.1 配置区

| 配置项 | 说明 |
|---|---|
| 压力名称 | 压测方案的名称（显示于日志头部） |
| 结束方式 | **次数**（跑满 N 轮）或 **时间**（到 N 分钟） |
| 行间隔(ms) | **全局默认**行间隔；某行单独设置了间隔则优先用该行值 |
| 响应超时(ms) | 收流判定：静默超过该时长认为本次响应结束 |

### 6.2 压测 AT list

与 AT list 一致，额外注意：

- **间隔**：每行可单独设置 `interval_ms`；**>0 时优先于全局行间隔**，0 表示用全局。间隔作用于"该行执行完成后"的等待。
- **预期结果**：默认 `OK`；可编辑为多个（用 `|` 分隔），匹配模式可选 contains/regex/exact。**空预期会按默认 `OK` 参与对比**，避免"没校验"。

### 6.3 开始 / 暂停 / 停止

- 点「开始」运行；运行中「开始」按钮显示当前**轮次数字**（绿色加粗）。
- 「停止」结束并输出汇总。

### 6.4 运行日志的结构

日志按轮分段，每轮首行有分隔标记，便于逐轮核对：

```
=== 名称:压力测试1 | 次数=5 | 行间隔(ms):300 | 响应超时(ms):2000 ===
=================== Runtimes 1 ===================
[2026-08-26_13:47:23:903]  TX  AT
[2026-08-26_13:47:24:019]  RX  AT
[2026-08-26_13:47:24:022]  RX  OK
=================== Runtimes 2 ===================
...
== 汇总 ==
压力名称: 压力测试1
测试时长: 0.0H
运行时间: 2026-08-26 13:47:23.900387~2026-08-26 13:47:28.197361
总运行次数: 5
已发送: 10
异常: 0
```

- **Runtimes N**：第 N 轮开始的标记。
- **异常**：预期不匹配 + 命中 check 规则的次数。
- **测试时长**：以小时、1 位小数展示（`0.0H`）。

### 6.5 自定义 check 规则

「自定义 check 规则」可配置关键字规则，命中即判异常并记录到目标(AT/DOS/BOTH)。示例内置：

- 模组异常重启 → `RDY`
- 响应含ERROR → `ERROR`

可新增/删除规则（默认关闭，需要时启用）。

---

## 7. 文件发送

切换到「文件」模式：选择本地文件 → 点「发送」按块写串口，带**进度条**与**暂停/恢复**；「取消」终止发送。发送结束后可继续下一次。

---

## 8. 中英切换

菜单「语言」选择 **中文 / English** 实时切换。切换会刷新主界面文字；部分新增/复杂控件可能在切换后不随动（见《已知限制与遗留项》）。

---

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 打不开串口 | 端口被占用 / 波特率不符 / 无权限（Linux 加 dialout 组） |
| 收不到数据 | 检查 DTR/RTS、波特率、设备是否回显；确认「显示」未关闭方向或时间戳 |
| 压力不校验结果 | 预期结果为空时按 `OK` 参与对比；确认该行已勾选且命令非空 |
| 压力结束无汇总 | 需满足结束条件（跑满次数/到时间）且至少执行过一轮 |
| 界面文字未随语言刷新 | 见《已知限制与遗留项》 |
